# ABDU’LLAH SHEDA | Book Marketing Specialist

The website for my book marketing services for authors.

## Features
- Futuristic dark design with a light mode toggle
- One-page and multi-page layouts, with a switch to change between them
- Nine service pages, 18 genre profiles, FAQ, resources and glossary
- Amazon page health check tool
- Contact form powered by Formspree
- Privacy Policy and Terms pages
- Responsive on phones, tablets and desktops

## How it's built
A single `index.html` file with HTML, CSS and JavaScript, so there is nothing to install or build.

## Run it
Open `index.html` in a browser, or publish it with GitHub Pages (Settings > Pages).
